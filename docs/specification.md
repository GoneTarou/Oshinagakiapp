# アプリ仕様

## コンセプト

同人即売会の一般参加者が、買いたいサークルの巡回リストを作成し、Xで共有・閲覧するためのWebアプリ。

用途は即売会の巡回専用とし、汎用的な外部ポスト整理サービスにはしない。

## ユーザー認証

- ログイン・ユーザー登録は作成しない
- `User`、`Session`、`Password`、OAuthは持たない
- 作成後のリストは編集・削除できない

## イベント

イベントは開催回を含む名称で運営側がDBに事前登録し、ユーザーは選択肢から選ぶ。

```text
コミックマーケットC108
コミックマーケットC109
COMITIA157
その他
```

- 開催回はイベント名に含めて管理する
- ユーザーによるイベント名の自由入力は行わない

## リスト作成

作成時にイベントと巡回先を登録する。リストタイトルは持たない。

- 共有URLは `/lists/:token`
- リスト一覧には公開しない
- URLを知っている人は閲覧できる
- 作成後にXで共有できる
- `token` は作成時に自動生成する一意のランダム値

## 巡回先

1リストにつき最大20件まで登録できる。

1リストにつき最低1件の巡回先を登録する必要がある。

| 項目 | 内容 |
| --- | --- |
| メモ | 任意。入力された場合は文字列で保存する |
| 外部ポストURL | 任意。X・pixivの許可されたURLのみ登録できる |
| イチ推し | 1リストにつき最大1件 |
| 成人向け | 成人向けコンテンツかどうか |

- メモが未入力の巡回先も登録できる
- メモと外部ポストURLが両方未入力の場合、イチ推し・成人向けのチェック状態に関係なく保存しない
- メモまたは外部ポストURLのどちらか一方が入力されていれば保存する
- 外部ポスト種別は保持せず、URLのホスト名から対応サイトを判定する
- メモは30文字以内
- 外部ポストURLは2,048文字以内
- Xは `x.com` のみ許可し、`twitter.com` は許可しない
- pixivは `pixiv.net` と `www.pixiv.net` のみ許可する
- 外部ポストURLは `http` または `https` のみ許可する
- 表示順はイチ推しを先頭にし、その他は登録順で固定する
- 並び替え機能は作成しない
- 価格、予算は扱わない

## 外部ポスト表示

- 外部コンテンツの画像・本文をアプリ側で保存・加工しない（Pixivタイトルは表示のため一時取得する）
- X APIは使用しない
- Xは公式 `widgets.js` で表示する
- Pixivはリスト表示後に作品タイトルだけを取得して表示する
- 成人向けPixivは「成人向けコンテンツを表示」で展開した後に作品タイトルを取得する
- PixivのタイトルはDBに保存しない
- その他のサイトは登録できない
- 外部ポストURLがない巡回先でも、メモ付きカードとして表示できる

## 閲覧画面

- daisyUIの `card-compact` を使用する
- 十分な画面幅では横3列・縦スクロールで表示する
- 狭い画面では列数を減らし、横スクロールを発生させない
- 巡回順はイチ推しを先頭にし、その他は登録順で上から下
- メモが入力されている場合はバッジで表示する
- メモが未入力の場合は、メモの表示を省略する
- 外部ポストの読み込みに失敗しても、メモとイチ推しは表示する

## 成人向けコンテンツ

- 成人向けフラグが付いた巡回先は通常の閲覧画面に表示するが、初期状態ではカード内容を隠す
- メモと「🔞 成人向け」の注意表示を初期状態で表示する
- 「成人向けコンテンツを表示」をクリックするとカード内容を表示する
- 通常ランキングには含めない
- 成人向けランキングは別URLで表示する
- 通常ページから、成人向けコンテンツを含む旨の注意文付きリンクを表示する
- 確認画面は表示しない

## 「みんなが選んでいる配置」ランキング

MVPでは実装しない。現在のメモ欄はランキングの集計対象にしない。

将来実装する場合は、メモ欄とは別に配置番号を管理する設計を検討する。

## 動的OGP

共有URLをXに投稿した際のOGP画像をRails側で生成する。

- MiniMagick、自作デザイン、テキスト描画を使用する
- サークルや外部ポストの画像は使用しない
- イベント名は20文字以内に制限する
- イベント名、全体サマリー、イチ推しのメモを表示する
- OGP上のイベント表示が16文字以上の場合は、文字サイズを40pxに縮小する
- イチ推しがない場合は、最初に登録された一般向け・メモ入力済みの巡回先を表示する
- メモがない場合は、メモを表示しない
- 成人向け巡回先の情報は通常OGPに含めない

## データ構成

```text
events
  └── lists
          └── list_items
```

| テーブル | 主な項目 |
| --- | --- |
| `events` | `name` |
| `lists` | `event_id`, `token` |
| `list_items` | `list_id`, `space_number`, `source_url`, `is_featured`, `is_adult_content` |

主な制約：

```text
UNIQUE(events.name)
UNIQUE(lists.token)
```

詳細なER図は [データベース構成](../mermaid.md) を参照する。
