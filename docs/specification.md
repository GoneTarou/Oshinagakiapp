# アプリ仕様

## コンセプト

同人即売会の一般参加者が、買いたいサークルの巡回リストを作成し、Xで共有・閲覧するためのWebアプリ。

用途は即売会の巡回専用とし、汎用的な外部ポスト整理サービスにはしない。

## ユーザー認証

- ログイン・ユーザー登録は作成しない
- `User`、`Session`、`Password`、OAuthは持たない
- 作成後のリストは編集・削除できない

## イベントと開催回

イベントと開催回は運営側がDBに事前登録し、ユーザーは選択肢から選ぶ。

```text
コミックマーケット
  - 106
  - 107
COMITIA
  - 150
その他
```

- 開催回は整数で管理する
- 通常イベントでは開催回の選択が必須
- 「その他」は開催回を持たず、`event_occurrence_id` はNULLとする
- ユーザーによるイベント名・開催回の自由入力は行わない

## リスト作成

作成時にイベント・開催回と巡回先を登録する。リストタイトルは持たない。

- 共有URLは `/lists/:token`
- リスト一覧には公開しない
- URLを知っている人は閲覧できる
- 作成後にXで共有できる
- `token` は作成時に自動生成する一意のランダム値

## 巡回先

1リストにつき最大20件まで登録できる。

1リストにつき最低1件の巡回先を登録する必要がある。

| 項目 | 内容 |
| --- | --- |
| 配置番号 | 任意。入力された場合は文字列で保存する |
| 外部ポストURL | 任意。X・pixivの許可されたURLのみ登録できる |
| イチ推し | 1リストにつき最大1件 |
| 成人向け | 成人向けコンテンツかどうか |

- 同一リスト内の配置番号重複は禁止する
- 配置番号が未入力の巡回先も登録できる
- 配置番号が未入力の巡回先はランキング集計から除外する
- 配置番号が未入力のカードは、配置番号未設定であることを表示する
- 配置番号と外部ポストURLが両方未入力の場合、イチ推し・成人向けのチェック状態に関係なく保存しない
- 配置番号または外部ポストURLのどちらか一方が入力されていれば保存する
- 外部ポスト種別は保持せず、URLのホスト名から対応サイトを判定する
- Xは `x.com` のみ許可し、`twitter.com` は許可しない
- pixivは `pixiv.net` と `www.pixiv.net` のみ許可する
- 外部ポストURLは `http` または `https` のみ許可する
- 表示順は登録順で固定する
- 並び替え機能は作成しない
- メモ、価格、予算、サークル名は扱わない

## 外部ポスト表示

- 外部コンテンツの画像・本文をアプリ側で保存・加工しない
- X APIは使用しない
- Xは公式 `widgets.js` で表示する
- その他のサイトは登録できない
- 外部ポストURLがない巡回先でも、配置番号カードとして表示できる

## 閲覧画面

- daisyUIの `card-compact` を使用する
- 十分な画面幅では横3列・縦スクロールで表示する
- 狭い画面では列数を減らし、横スクロールを発生させない
- 巡回順は左から右、上から下
- 配置番号が入力されている場合は `badge-error`、イチ推しは `👑 推し` と `badge-warning` で表示する
- 配置番号が未入力の場合は、配置番号未設定と表示する
- 外部ポストの読み込みに失敗しても、配置番号とイチ推しは表示する

## 成人向けコンテンツ

- 成人向けフラグが付いた巡回先は通常の閲覧画面に表示するが、初期状態ではカード内容を隠す
- 配置番号と「🔞 成人向け」の注意表示を初期状態で表示する
- 「成人向けコンテンツを表示」をクリックするとカード内容を表示する
- 通常ランキングには含めない
- 成人向けランキングは別URLで表示する
- 通常ページから、成人向けコンテンツを含む旨の注意文付きリンクを表示する
- 確認画面は表示しない

## 「みんなが選んでいる配置」ランキング

同じイベント・開催回で、同じ配置番号が登録されたリスト数を集計する。配置番号未入力の巡回先は集計しない。

```text
コミックマーケット106
東A-12b → 52件登録
```

- ユーザー数ではなく、配置番号がリストに登録された回数を表示する
- 同一リスト内の入力済み配置番号重複を禁止し、水増しを防ぐ
- 通常ランキングは一般向け巡回先のみを集計する
- 成人向けランキングは成人向け巡回先のみを別ページで集計する
- MVPでは上位10件を表示する
- 「その他」は集計対象外
- サークルマスタや `circles` テーブルは作成しない

## 動的OGP

共有URLをXに投稿した際のOGP画像をRails側で生成する。

- MiniMagick、自作デザイン、テキスト描画を使用する
- サークルや外部ポストの画像は使用しない
- イベント名・開催回、全体サマリー、イチ推しの配置番号を表示する
- 成人向け巡回先の情報は通常OGPに含めない

## データ構成

```text
events
  └── event_occurrences

events
  └── lists
          └── list_items
```

| テーブル | 主な項目 |
| --- | --- |
| `events` | `name` |
| `event_occurrences` | `event_id`, `number` |
| `lists` | `event_id`, `event_occurrence_id`, `token` |
| `list_items` | `list_id`, `space_number`, `source_url`, `is_featured`, `is_adult_content` |

主な制約：

```text
UNIQUE(events.name)
UNIQUE(event_occurrences.event_id, event_occurrences.number)
UNIQUE(lists.token)
UNIQUE(list_items.list_id, list_items.space_number) ※配置番号が入力された場合
```

詳細なER図は [データベース構成](../mermaid.md) を参照する。
