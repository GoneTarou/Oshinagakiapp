# 即売会しおり

本番URL：[https://oshinagakiapp.onrender.com/](https://oshinagakiapp.onrender.com/)

## 1. サービス概要

即売会しおりは、コミックマーケットやCOMITIAなどの同人即売会に参加する一般参加者向けの、巡回リスト作成・共有Webアプリです。

イベントを選び、買いたいサークルの作者名・サークル情報やX・pixivのURLを登録すると、スマートフォンで確認しやすい巡回リストを作成できます。作成したリストには共有URLが発行され、リスト詳細画面からXに共有できます。

ログインやユーザー登録は必要ありません。作成後のリストは編集・削除できない、使い切りに近いシンプルな設計です。

## 2. 想定ユーザーについて

### 想定しているユーザー

- 同人即売会に一般参加する人
- コミックマーケット、COMITIAなどで複数のサークルを回る人
- イベント前にXのお品書きやpixiv作品を確認しておきたい人
- 友人やフォロワーと巡回先を共有したい人

### 利用する場面

- 即売会の開催前に、Xやpixivで気になるサークルを見つけたとき
- 自分の巡回リストをXで友人や買い子に共有するとき
- イベント終了後に、購入したサークルや巡回先を共有するとき

### ユーザーとの距離

開発者自身も同人イベントに参加する一般参加者として、次のような課題を感じています。

- Xのお品書きや投稿を後から探し直す手間がある
- イベント当日に巡回先を確認しづらい
- メモアプリやSNSなど複数のサービスを行き来する必要がある
- 友人と巡回先を共有するために、情報をまとめ直す必要がある

## 3. 既存サービス・競合調査

### 同人イベント向けサービス

| サービス | 主な特徴 | 即売会しおりとの違い |

| [NITO-GET](https://www.nununu-zakki.com/nitoget-release/) | 同人イベントの買い物リスト、当日モード、チェック機能などに対応 | 即売会しおりは個人の買い物管理よりも、リストの作成・共有を重視する |

### 即売会しおりを作る理由

既存サービスには多くの機能がある一方、次のような導入時の負担があります。

- アプリのインストールが必要
- ユーザー登録やログインが必要
- 地図やカタログなど、多くの機能を覚える必要がある
- 自分の使いたい情報だけを短時間で登録しづらい

即売会しおりは、イベントを選んで巡回先を入力し、発行されたURLを共有するだけの流れに絞ります。

## 4. このサービスで提供したい価値

### ユーザーの変化

行動の変化：

- Xやpixivの投稿を後から探し直す時間が減る
- 即売会前に巡回先を整理できる
- 当日は共有ページを開くだけで巡回先を確認できる
- 友人や買い子に同じリストを共有できる

気持ちの変化：

- イベント前の準備に安心感が生まれる
- 当日に巡回先を忘れる不安が減る
- 複数のサービスを行き来するストレスが減る

### 提供したい価値を一文で表す

「即売会に参加する人が、気になるサークルの情報を簡単に整理し、当日に確認しやすい形で共有できるサービス」です。

## 5. このアプリで実現すること

### MVPで実現する機能

1. **イベントを選択する**
   - 運営側がDBに登録したイベントから選択する
   - イベント名には開催回を含める
   - 「その他」も選択できる

2. **巡回先を登録する**
   - 作者名またはサークル情報を登録する
   - XまたはpixivのURLを登録する
   - 作者名・サークル情報は100文字以内
   - 外部ポストURLは2,048文字以内
   - 作者名・サークル情報またはURLのどちらか一方を必須とする
   - 1リストにつき最大20件まで登録する
   - 最初は5件を表示し、「巡回先を追加する」で入力欄を増やす
   - イチ推しは1件だけ選択できる
   - 成人向けかどうかを設定できる

3. **リストを作成する**
   - ログイン・ユーザー登録なしで作成できる
   - 作成時にランダムな共有トークンを発行する
   - 作成後の編集・削除はできない
   - リスト一覧には公開しない

4. **共有ページで確認する**
   - 共有URLを知っている人が閲覧できる
   - イチ推しを先頭にし、その他は登録順で表示する
   - Xの投稿は公式ウィジェットで表示する
   - pixivは「pixivで開く」リンクを表示し、タイトルを取得して表示する
   - 成人向けカードは初期状態で内容を隠し、クリック後に表示する
   - リスト詳細画面の上部と下部にX共有ボタンを表示する

5. **OGP画像を生成する**
   - 共有ページにイベント名と巡回先件数を表示する
   - イチ推し、または最初に登録された一般向け巡回先を表示する
   - Xで共有したときに、内容が分かる画像を表示する

### MVPで実装しないこと

- リストの編集・削除
- 価格・予算・購入状況の管理

## 6. このアプリの懸念点とその対策

### 懸念点1：共有URLを知られると誰でも閲覧できる

ログイン機能を持たないため、共有URLを知っている人はリストを閲覧できます。

対策として、URLには推測しにくいランダムトークンを使用し、リスト一覧や検索結果には表示しません。共有URLをSNSなどに公開する場合は、内容を見られても問題ない情報だけを登録する必要があります。

### 懸念点2：作成後に入力ミスを修正できない

作成後の編集・削除ができないため、入力ミスがあっても修正できません。

作成前に入力内容を確認できる画面構成にし、URL・作者名・サークル情報のエラーは該当する入力欄の近くに表示します。将来的には、作成者だけが編集できる機能を検討します。

### 懸念点3：外部サービスの仕様変更や障害の影響を受ける

Xのウィジェットやpixivのページ構造が変更された場合、外部ポストやタイトルを表示できなくなる可能性があります。

Xの表示に失敗した場合も外部URLへのリンクを残し、pixivは「pixivで開く」リンクから元ページを確認できるようにします。外部URLはXとpixivだけに制限し、Pixivタイトル取得にはタイムアウトとリダイレクト回数の制限を設けています。

### 懸念点4：成人向け情報の扱い

成人向けかどうかはユーザー入力に依存するため、完全に正確とは限りません。

成人向けフラグが付いた巡回先は、通常の共有ページではカード内容を初期状態で隠し、「成人向けコンテンツを表示」をクリックした場合だけ展開します。登録時にユーザーが適切に設定することを案内します。

### 懸念点5：大量アクセスによる負荷

OGP画像の生成やPixivタイトルの取得にはサーバー処理と外部通信が発生します。共有URLが大量にアクセスされた場合、サーバーや外部サービスへの負荷が増える可能性があります。

外部通信のタイムアウトと取得サイズの上限を設定しています。今後はOGP画像のキャッシュやIP単位のレート制限も追加します。

## 7. 今後の展開・発展の方向性

### 機能追加の方向性

- 「みんなが選んでいる配置」ランキング
- 成人向け配置ランキング
- イベントごとの会場マップ
- 配置番号やサークル情報の選択式入力
- サークル名・価格・購入状況・メモの管理
- 巡回先作成時の並び替え

### ユーザー体験の改善

- スマートフォンでの入力負担をさらに減らす
- Xやpixivからの情報入力を簡単にする
- オフラインでも共有ページを確認できるようにする
- 会場で確認しやすい大きな文字やチェック機能を追加する
- 画像や外部サービスに依存しない簡易表示を用意する

### 継続利用につなげる方法

利用者からの意見をもとに、イベント前の準備と会場での閲覧の両方を改善していきます。
