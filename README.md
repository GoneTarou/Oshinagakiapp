# 即売会巡回リスト共有Webアプリ 仕様書

## 1. アプリ概要

### コンセプト

同人即売会（コミケ等）の一般参加者が、**買いたいサークルの巡回リストを素早く作成し、Xで共有し、会場で確認するためのWebアプリ**。

### ターゲット

同人即売会の一般参加者（買い手）。

### コア体験

```text
Xで気になるサークルを見つける
        ↓
XポストURLを登録
        ↓
配置番号を入力
        ↓
巡回リスト完成
        ↓
Xで共有
        ↓
会場で3列表示を見ながら巡回
```

---

# 2. 用途の限定

このアプリは**同人即売会の巡回専用**とする。

技術的にはXポストを並べる仕組みなので他用途にも利用できるが、プロダクトとしては汎用的な「Xポスト整理サービス」にはしない。

UI・DB・文言を即売会に特化させる。

例えば、

* サークル
* 配置番号
* 巡回
* イチ推し
* 会場
* お品書き

などの概念を使用する。

---

# 3. Xポストの表示

ユーザーがサークル主のXポストURLを登録し、閲覧画面ではX公式の `widgets.js` を利用してポストを埋め込む。

## アプリ側で保存するもの

```text
XポストURL
```

のみ。

サークル主のお品書き画像などをアプリ側にダウンロード・保存・加工しない。

## 表示

```text
XポストURL
     ↓
X公式 widgets.js
     ↓
アプリ内カードに埋め込み
```

これにより、Xの投稿表示部分を自前で再実装する必要がない。

---

# 4. X共有仕様

## サークル主への通知

アプリからサークル主へ意図的な通知を発生させない。

共有投稿では、

* `@アカウント名` を付けない
* サークル主の投稿を引用リポストしない
* サークル主の公式ポストURLを投稿本文に直接含めない

という方針にする。

共有するのは、アプリが生成した巡回リストのURL。

---

## 共有投稿例

```text
コミケ1日目 巡回ルートできました！

一番の狙い目は 東A-12b 🔥

📋 巡回スペース一覧
東A-12b / 東B-04a / 西れ-05a / 南1-01a

#即売会巡回ポータル
https://example.com/lists/a1b2c3d4
```

配置番号を投稿本文に含めることで、サークル主がエゴサーチした際に偶然発見できる可能性を作る。

# 5. 動的OGP

共有URLをXに投稿した際に表示されるOGP画像をRails側で生成する。

## 使用技術

* MiniMagick
* 自作デザイン
* テキスト描画

サークル主の画像はOGP生成に使用しない。

## OGPに表示する内容

### リストタイトル

```text
コミケ1日目 巡回ルート
```

### イチ推し

最も目立つ位置に表示。

```text
👑 イチ推し

東A-12b
○○サークル
```

※サークル名はMVPではXポストから取得せず、必要に応じてユーザーが入力する仕様を後から検討する。

### 全体サマリー

```text
全8サークル
```

予算情報は扱わない。

# 6. 閲覧画面

## レイアウト

**横3列 × 縦スクロール**。

```text
┌────────┬────────┬────────┐
│ カード1 │ カード2 │ カード3 │
├────────┼────────┼────────┤
│ カード4 │ カード5 │ カード6 │
├────────┼────────┼────────┤
│ カード7 │ カード8 │ カード9 │
└────────┴────────┴────────┘
```

基本的に横スクロールは発生させない。

会場で、

**左 → 右 → 上 → 下**

の順番で確認できる構成にする。

# 7. 巡回カード

daisyUIの `card-compact` を使用。

## ヘッダー

### 配置番号

`badge-error` を使用。

```text
東A-12b
```

遠くからでも確認しやすいように目立たせる。

### イチ推し

`is_featured = true` の場合のみ、

```text
👑 推し
```

を `badge-warning` で表示。

1リストにつき1件のみを想定。

## MVPではメモなし

カードには**メモ入力を設けない**。

MVPでサークルについてユーザーが入力する情報は、

* XポストURL
* 配置番号
* イチ推し設定

のみ。

---

# 8. Xポスト部分

カードのボディにはX公式Widgetを表示する。

```text
┌──────────────────┐
│ 🔴 東A-12b        │
│ 👑 推し            │
├──────────────────┤
│                    │
│   X公式ポスト       │
│   お品書き画像       │
│                    │
└──────────────────┘
```

---

# 9. 通信障害対策

X Widgetは通信が必要なので、完全なオフライン表示は目的としない。

ただし、カード上部の

* 配置番号
* イチ推し

はRailsが返したHTMLとして表示できる。

そのため、

> **通信がなくても「次にどこへ行くか」は確認できる**

という設計にする。

Xポスト自体は通信環境が必要。

# 10. データベース

MVPでは2テーブル。

## `lists`

巡回リスト本体。

| カラム          | 型        | 制約               | 説明         |
| ------------ | -------- | ---------------- | ---------- |
| `id`         | bigint   | PK               | 主キー        |
| `title`      | string   | NOT NULL         | リストタイトル    |
| `token`      | string   | NOT NULL, UNIQUE | 共有URL用トークン |
| `created_at` | datetime |                  | 作成日時       |
| `updated_at` | datetime |                  | 更新日時       |

### 持たないもの

* `budget`
* `user_id`
* その他ユーザー情報

---

## `list_items`

巡回するサークル。

| カラム            | 型          | 制約            | 説明            |
| -------------- | ---------- | ------------- | ------------- |
| `id`           | bigint     | PK            | 主キー           |
| `list_id`      | references | NOT NULL      | 所属リスト         |
| `tweet_url`    | string     | NOT NULL      | サークル主のXポストURL |
| `space_number` | string     | NOT NULL      | 配置番号          |
| `is_featured`  | boolean    | DEFAULT false | イチ推しフラグ       |
| `created_at`   | datetime   |               | 作成日時          |
| `updated_at`   | datetime   |               | 更新日時          |

### 持たないもの

* `memo`
* `price`
* `budget`

---

# 11. モデル関連

```ruby
class List < ApplicationRecord
  has_many :list_items, dependent: :destroy
end
```

```ruby
class ListItem < ApplicationRecord
  belongs_to :list
end
```

1つのリストに複数のサークルを登録する。

---

# 12. イチ推し

`list_items.is_featured` で管理する。

```text
List
 ├─ ListItem
 ├─ ListItem
 ├─ ListItem ← is_featured = true
 └─ ListItem
```

1つのリストにつき1件のみを想定。

Railsのバリデーション等で制御する。

---

# 13. 共有URL

ログイン不要で閲覧可能。

```text
/lists/:token
```

例：

```text
https://example.com/lists/a1b2c3d4
```

## token

`SecureRandom` を利用して予測困難なランダム文字列を生成する。

URLを知っている人だけがリストを閲覧できる。

# 14. 認証

**ログイン機能は実装しない。**

* User

* Password
* OAuth

などの認証関連テーブルを作らない。

# 21. プロダクトの核心

このアプリの目的は、

**Xのポストを保存・整理することではない。**

あくまで、

> **即売会で「どのサークルへ行くか」を素早く確認するための巡回ツール**

である。

Xのポスト埋め込みは手段であり、中心となる価値は、

```text
気になるサークルを見つける
        ↓
配置番号とXポストを登録
        ↓
巡回リストを作る
        ↓
共有する
        ↓
会場で3列表示を見ながら回る
```

という一連の体験にある。

**「即売会専用」にすることで、汎用的なXブックマークサービスとの差別化を図る。**
