# 即売会巡回リスト共有Webアプリ MVP仕様書

## 1. コンセプト

同人即売会の一般参加者が、買いたいサークルの巡回リストを作成し、Xで共有・閲覧するためのWebアプリ。

用途は同人即売会の巡回専用とし、汎用的なXポスト整理サービスにはしない。

## 2. コア体験

```text
即売会を選択
    ↓
巡回先を追加
    ↓
配置番号・外部ポストURLを入力
    ↓
必要ならイチ推し・成人向けを設定
    ↓
リスト作成
    ↓
共有URLを発行
    ↓
Xで共有
    ↓
会場で3列表示を見ながら巡回
```

## 3. ユーザー認証

ログイン・ユーザー登録は作成しない。

- `User`、`Session`、`Password`、OAuthは持たない
- リスト作成者は管理しない
- 作成後の編集・削除はできない

## 4. イベント

イベントと開催回は運営側がDBに事前登録する。ユーザーは登録済みの選択肢から選ぶ。

例：

```text
コミックマーケット
  - 106
  - 107
COMITIA
  - 150
その他
```

- 開催回は `integer` で管理する
- `その他` の場合は `event_id` のみ設定する
- `その他` は開催回を持たず、`event_occurrence_id` は `NULL` とする
- ユーザーによるイベント名・開催回の自由入力は行わない

## 5. リスト

リストタイトルは持たず、イベントと開催回をリストのコンテキストとする。

共有URLの形式：

```text
/lists/:token
```

- リスト一覧には公開しない
- 作成完了時に共有URLを発行する
- Xで共有できる
- URLを知っている人は共有ページを閲覧できる

## 6. 巡回先

1リストにつき最大20件まで登録できる。

各巡回先で入力・保存する項目：

- 配置番号
- 外部ポストURL
- イチ推しかどうか
- 成人向けかどうか

制約：

- 配置番号は文字列として保存する
- 同一リスト内の配置番号重複は禁止する
- 1リストにつきイチ推しは最大1件
- 巡回先は登録順で固定する
- 並び替え機能は作成しない
- メモ、価格、予算、サークル名は扱わない

## 7. 外部ポスト表示

Xに限定せず、pixivなどの外部ポストURLを登録できる。

アプリ側では外部コンテンツを保存・加工しない。

- 画像を保存しない
- 画像を加工しない
- ポスト内容をDBにコピーしない
- X APIを使用しない
- Xは公式 `widgets.js` で表示する
- その他のサイトはサイトごとの埋め込み、または外部リンク表示とする

## 8. 巡回カードと閲覧画面

daisyUIの `card-compact` を使用し、横3列・縦スクロールで表示する。

- 配置番号はカード上部に `badge-error` で表示する
- イチ推しは `👑 推し` と `badge-warning` で表示する
- 外部ポストをカード内に表示する
- 巡回順は左から右、上から下とする
- X等の読み込みに失敗しても、配置番号とイチ推しは表示する

## 9. 成人向けコンテンツ

成人向けフラグが付いた巡回先は、通常の閲覧画面・通常ランキングには表示しない。

成人向けランキングは別ページで表示する。

- 成人向け巡回先のみを集計する
- 通常ページから成人向けランキングへのリンクを表示する
- 成人向けランキングは別URLとする

URL例：

```text
/lists/:token/rankings
/lists/:token/adult-rankings
```

## 10. 「みんなが選んでいる配置」

イベントの開催回単位で、配置番号を登録した共有可能なリスト数を集計する。

例：

```text
コミックマーケット106
東A-12b → 52件
```

この数字はサークルやXの人気ではなく、同じ配置を巡回先として登録したリスト数を表す。

- 通常ランキングは一般向け巡回先のみを集計する
- 成人向けランキングは別ページで集計する
- MVPでは上位10件を表示する
- `その他` はランキング集計対象外とする
- 専用の `events` 以外のサークルマスタや `circles` テーブルは作成しない

## 11. 動的OGP

共有URLをXに投稿した際のOGP画像をRails側で生成する。

使用技術：

- MiniMagick
- 自作デザイン
- テキスト描画

サークルの画像はOGP生成に使用しない。

OGPには以下を表示する。

- イベント名・開催回
- 全体サマリー
- イチ推しの配置番号

成人向け巡回先の情報は通常OGPに含めない。

## 12. データベース構成

```text
events
  └── event_occurrences
          └── lists
                  └── list_items
```

### `events`

```text
id
name
created_at
updated_at
```

### `event_occurrences`

```text
id
event_id
number
created_at
updated_at
```

### `lists`

```text
id
event_id
event_occurrence_id  # NULL許可
token                # UNIQUE, NOT NULL
created_at
updated_at
```

### `list_items`

```text
id
list_id
space_number
source_url
is_featured
is_adult_content
created_at
updated_at
```

主な制約：

```text
UNIQUE(event_id, number)
UNIQUE(list_id, space_number)
```

- `event_occurrence_id` がある場合、`lists.event_id` と同じイベントに属する
- `list_items` は1リスト最大20件
- `is_featured = true` は1リストにつき最大1件
